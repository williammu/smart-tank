# viz/ · 神经网络可视化

三个单文件自包含 HTML（深色主题，无外部依赖），按学习顺序排列：

| 文件 | 内容 | 交互 |
|---|---|---|
| `index.html` | 全连接层静态图（4 输入 × 5 神经元 = 20 条连接） | 悬停节点看它的连接；点击隐藏神经元看加权求和公式；🎲 随机权重 |
| `forward-pass.html` | 前向传播五幕动画：输入 → 乘权重 → 求和+偏置 → ReLU → 输出 | 播放/暂停/跳幕/调速；`?s=幕&t=秒` 定位任意帧；含"死神经元"演示 |
| `output-layer.html` | 输出层细节：128 → 9 个动作 → softmax 概率 | 悬停神经元看 9 条线；点动作看 128 项求和 top 贡献者；🎲 换局面；按概率采样 |
| `dataset.html` | 标签数据集浏览器（dataset-v1，400 条抽样） | 每条样本反推成小竞技场画面；按动作类过滤（`?f=0..4`）；点卡片看 37 维全量。数据由 `scripts/export_dataset_viz.py` 注入 |
| `backprop.html` | 反向传播的魔法：一遍逆流算出全部的锅 | 迷你网络 2→2→2 全真数字（与笔记手算版一致）：前向记账 → P−y 起手 → 锅逆流分锅（×搭档）→ ReLU 闸门 → 责任账 12 份 → 拧旋钮 loss 0.30→0.20。`?s=幕&t=秒` 定点 |

约定：绿线=正权重、红线=负权重、粗细=|w|；灰点=被 ReLU 归零的死神经元；金色=argmax/输出。
