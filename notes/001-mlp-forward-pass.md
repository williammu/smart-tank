# 001 · MLP 与前向传播（2026-09-27）

> 来源：智能坦克项目启动时的第一次设计讨论。配套可视化：`viz/`（index / forward-pass / output-layer）。

## 网络结构（坦克项目设定）

```
输入(20) → 隐藏层h¹(128) → 隐藏层h²(128) → 输出层(9个动作)
每层之间都是全连接：h = ReLU(W·x + b)，输出层例外（不过 ReLU，接 softmax）
```

- **MLP = 多层感知机**：几层全连接神经元，信息单向流动。是"深度神经网络"（DNN）的原型——DNN 就是它堆更多层，没有新机制。
- **输入"层"没有神经元**：20 个圆圈只是数据占位，真正计算的从 h¹ 开始。

## 核心机制（一条条确认过的认知）

1. **每个输入 x 是标量**，被复制广播到下一层每个神经元，每份乘**不同的**权重；权重之间永不互相运算。
2. **权重是"线"的属性，不是节点的属性**：wᵢⱼ = 输入 i → 神经元 j 那条线上的数。每个神经元的权重数 = 上一层维度。
3. **一个神经元 = 把它收到的全部乘积求和 + 偏置 b → ReLU**：`ReLU(z)=max(0,z)`，正数通过负数归零。z<0 的神经元本轮输出 0，"不参与决策"（死神经元现象）。
4. **为什么需要 ReLU**：没有激活函数，多少层线性变换叠起来都等价于一层。ReLU 提供"折弯"，深度才有意义。
5. **维度变换 = 全员加权投票**：128→9 不是压缩丢弃，是 9 个输出神经元各自用一套独立的 128 个权重，把 128 个数加权和成 1 个分，做 9 次。
6. **输出层两个例外**：不过 ReLU（负分="这个动作很糟"，是合法信息）；9 个 z 过 softmax（`P(k)=e^zk/Σe^zi`）变概率分布。
7. **动作选择**：对战取 argmax；训练按 P 采样（低概率动作也有机会被试 = 探索）。

## 参数量（精确可算）

```
每层参数 = 输入维×输出维(w) + 输出维(b)
h¹: 20×128+128 = 2,688   h²: 128×128+128 = 16,512   输出: 128×9+9 = 1,161
合计 20,361 ≈ 2万（大头是中间层 128×128，占 80%）
```

## 超参数认知（128 怎么来的）

- **128 是拍的，不是算的**：2 的幂（硬件友好）+ "比输入大一个量级"的经验起点 + 训练成本取舍。
- **加宽 vs 加深**：加深买"多一级抽象"（参数效率高但难训练），加宽买"同层更多看法"（稳但参数膨胀）。RL 里"好训练"比"理论容量"值钱。
- **一个隐藏层够吗**：万能近似定理说理论上够（宽度不限可逼近任意连续函数）；实际损失是参数效率（特征不能复用）和优化路径。坦克 1v1 决策只有一层抽象，1×128 大概率够用。
- **参照**：stable-baselines3 的 PPO 默认策略网络仅 2×64。
- **方法论**：从最小结构往上升，靠训练曲线（奖励平台高度 + 对历史版本胜率）判容量，别一次到位。
