# 004 · 路线C第①步：规则老师与人造标签数据集（2026-09-27）

> 产物：`scripts/rule_teacher.py`（入门级规则老师）· `scripts/record_data.py`（录制器）· `data/dataset-v1.npz`（gitignored）
> 决策：用户拍板路线 C（SL 热身 → RL 突破），老师定入门级。

## 标签是什么（认知定稿）

标签 = 训练数据里每条输入旁边的"标准答案"。坦克版：`(37维观测, 动作编号0-4)` 一行一条。
关键认知：**标签≠真理，标签=老师当时的选择**——SL 天花板=老师水平的数学根源。
人造标签 = 让 if-else 规则机器人下场打，每步把"看到的局面+做的决定"存一行。

## 老师设计

- **只看 37 维观测做决策，不碰游戏内部状态** → 顺便实证观测完备性（马尔可夫性从假设变验证结论）；
- 决策树：没对准→转向；对准+视线畅通+冷却就绪→开火；否则调整距离（太远前进/贴脸后退）；
- 刻意入门级：不躲弹、不算提前量——留给 RL 阶段超越的空间；
- 瞄准容差随距离缩放（atan(18/d)）：远了必须瞄更准，否则"开火"标签混进必 miss 的坏示范（notes/002 的几何账）。

## 数据卫生军规（每条都有实测事故背书）

1. **train/val 按局切分**（同局相邻帧近乎重复，随机切 = 考题漏进练习册）；
2. **看类别分布** → 抓到：固定出生点让对局退化成"中线对射"（左转/右转/后退全是 0.0%，每局仅 86 步）→ arena.reset 改随机出生（位置+朝向随机、间距≥250、不落掩体）；
3. **只录活坦克的决策**；
4. **随机对手的决策绝不录成标签**（垃圾进垃圾出）；且两个同策略老师对打会陷"逼近→后退"镜像僵局（后退占 40%）→ 改混合对手：一半 vs 老师（双视角录）、一半 vs 随机策略（只录老师）。

## 最终数据集 v1

```
200 局 → train 281,315 / val 24,631（按局 90/10）
分布：前进 86.1% / 后退 10.3% / 左转 1.5% / 右转 1.4% / 开火 0.7%
老师战绩：命中率 7.7%（509/6640），平均每局 1010 步
```

- 类别不平衡显著（开火 0.7%）——诚实保留，**训练时用类别权重/过采样处理**（下一步的课）；
- 老师命中率 7.7% 是"打移动靶不算提前量"的诚实天花板——站桩对射时曾 80%，随机出生后现原形。
