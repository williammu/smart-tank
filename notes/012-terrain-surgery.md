# 012 · 地形改造：终审定理的实验验证

日期：2026-09-28 ｜ 状态：✅ v14 命中奖 1.0 + 免弹药费——站桩率首次跌出引力中心，双犯模型双层实锤

## 一句话

按终审定理开出的药方（命中奖 0.2→1.0、弹药费 0.01→0，盲射罚保留）果然扳动了指标：**站桩率 58.4%→50.5%（历代最大单炉降幅）+ 训练坠崖吸引子消失**。"地形决定吸引子，算法只决定速度"从判决升级为已验证定律；剩余 ~50% 站桩归几何层，奖励改不动。

## 实验设计（可证伪预言的生死状）

- 预言：若地形决定吸引子，则让"瞄准开炮"局部划算（EV=p×1.0−0>0）后站桩率应跌出 58~63% 引力中心；若不动，几何层是唯一犯人
- 纪律：只改奖励表两个数（--hit-reward 1.0 --fire-cost 0.0），引擎/起点/其余 shaping 与 v8 一字不差

## 结果（200 轮，从 rl-v8 出发）

| 指标 | v8 | v14 |
|---|---|---|
| 站桩率 | 58.4% | **50.5%** |
| 月考 | +15 后振荡 | +11 缓降至 0，**无坠崖**（v12/v13 同预算 −14/−18） |
| 僵局率 | ~50% | 36~50% |
| 局均步 | ~1000 | 791~895 |

## 双犯模型最终状态

```
地形层（奖励期望不对称）✅ 已验证可改造：站桩 −8 点 + 吸引子拆除
几何层（掩体挡视线+同速风筝）✅ 已验证不可由奖励改造：~50% 站桩铁板
```

## 项目至此的科学闭环

诊断（九代排除法）→ 终审（双犯模型）→ 实验验证（v14 扳动地形层）——
从"坦克为什么蹲坑"到"我们证明了它为什么蹲、以及哪部分能改"。
