# 003 · 观测设计：看不见的 = 不存在的（2026-09-27）

> 触发：我发现 20 维观测里没有障碍物。结论：是缺陷，当日修复（20 维 → 29 维）。

## 原则

**观测向量是智能体的全部感官。动力学需要、而观测里没有的信息，智能体就是"瞎的"——要么学不会，要么烧网络容量硬背。**

- 掩体是静态的，理论上网络能从"撞了不动"的经验里背出位置——但那是拿训练时间和参数量换我们免费能给的信息；
- 缺掩体感还破坏马尔可夫性：同样"前进"，有时动有时不动，从观测里看不出规律，转移不可预测 → 学习变难；
- 没有视线信息，学不会"这枪会打墙、忍住别开火"，更学不会"躲掩体后/绕掩体包抄"。

## 修复（arena.py v0.2）

观测 20 → 29 维：
- #20-27：4 个掩体中心相对位置 (dx, dy)/场地尺寸（静态物体给相对坐标即可）；
- #28：视线遮挡 bit——敌我连线是否被掩体挡住（0=畅通可开火，1=被挡）。

网络输入层相应 20→29（参数 19,845 → 20,997）。验证：出生点互望 bit=0，敌人躲进掩体后 bit=1。

## 配套认知

- **"故意不给"也是合法设计**：部分可观测（战争迷雾）是增加难度/真实感的旋钮——但那是练出基础能力之后的进阶选项，不是起步该背的债。
- 排查"学不会"时的检查清单于是有四步了：环境不可能（动作空间，notes/002）→ 环境物理 bug（掩体堵弹道）→ **观测不全（本篇）** → 才轮到算法/网络。

## 数据契约（v0.3 现状）

输入 37 维（原 20 + 掩体 4×(dx,dy,半宽,半高)=16 + 视线 1）→ MLP 37→128→128→5（22,021 参数）→ softmax → 采样/argmax。
奖励与训练循环仍未接——下一步：反向传播 → REINFORCE。

## 追问：尺寸需要给吗？（v0.2 → v0.3）

三层判断：
1. **当前非必须**：掩体静态 + 槽位固定（#20 起永远是 0 号掩体），尺寸是常量，网络可以靠槽位隐式记住；且物理层（碰撞/视线 bit）一直用精确几何。
2. **给了更好**："边缘 = 中心 ± 半宽"从要学的知识变成白给的线性运算，RL 每步都贵，能白给的不让它学。
3. **未来变必须**：随机地图（每局换掩体布局）时槽位记忆失效——凡随局变化的量必须进观测。提前铺平。

> 原则补全：**常量可以靠权重记（槽位隐式），变量必须进观测；但显式给出永远比让网络学便宜。**
